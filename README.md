# ✅ TaskMate – Java To-Do List App

TaskMate is a beginner-friendly desktop application built using **Java Swing**. It allows users to create, manage, save, and load their daily to-do tasks. It's lightweight, simple to use, and a great project to learn Java GUI and file handling concepts.

---

## 🚀 Features
- Add new tasks with ease
- Delete selected tasks
- Save tasks to a local file (`tasks.txt`)
- Load tasks anytime, even after restarting
- Simple and intuitive GUI using Java Swing

---

## 🛠️ Tech Stack
- **Java**
- **Swing** (GUI development)
- **File I/O** (Saving and loading tasks)
